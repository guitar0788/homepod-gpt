# Siri Plus 1.0 RC 交付验收

版本：1.0.0 (10)。本项目为 Siri 的第三方增强应用，不替换 Siri。

## 已纳入 CI
- 家庭场景规则 7 项
- 本地模型只读计划校验 10 项
- 组合服务规则 10 项
- 统一入口安全路由 14 项
- iPhone arm64 Release 编译、IPA ZIP 校验、SHA256

## 安装前
- 从成功的 GitHub Actions 对应提交下载 PrivateAssistant-unsigned artifact，核对 SHA256。
- IPA 未签名，需要兼容签名方式并保留 HealthKit entitlement；不保证个人签名可用。
- 不在仓库中保存签名凭据或 API 令牌。
- 不要求购买开发者会员或 Apple Music；已有订阅与授权决定可用音乐曲库。

## 设备验收（未执行）
1. 安装、启动、验证原语音令牌；先测试时间、天气，不消耗模型额度。
2. 天气默认城市设置后测试今天、明天、穿衣建议及错误城市。
3. 测试普通问答、近期对话开启后的追问和重复回答。
4. 分项授权健康、音乐、日历、提醒、闹钟、通知，未授权时应明确失败。
5. 通过独立认证入口读取健康、日历、回家简报；拒绝认证时不得读取。
6. 测试播放、暂停、切歌，核实实际音频输出；不能仅凭返回文案认定成功。
7. 设置短时间计时和明确的未来闹钟，确认手机真实响铃；不要依赖未验收功能作为唯一重要闹钟。
8. 测试组合请求确认、拒绝和否定；确认拒绝时无动作执行。
9. 测试 HomePod 语音入口、锁屏、实际朗读。第三方接口不能持续占用 HomePod 麦克风或替换系统 Siri。
10. 免费模型故障不得自动转入 DeepSeek。未经单独安排不要做付费模型实测。

所有设备项目必须真实通过后才能标记正式验收。编译不等于功能已在设备上可用。
